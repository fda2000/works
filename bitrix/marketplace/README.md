Образец обновления модуля в маркетплейсе битрикса. Модуль изначально старый, делался не мной, его структура не моя. 
Я сделал возможность обновления его через маркетплейс и поддерживал функционирование при обновлениях битрикса, 
при переходе на новые версии php, переписывал на D7 где было необходимо, добавлял различный функционал.
Обновления делались так, чтобы максимально сохранить кастомизации пользовательских сайтов (при условии соблюдения ими установленных правил).
